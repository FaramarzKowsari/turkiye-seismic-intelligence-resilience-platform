# DepremNabız AI v1.0.0

## Public Research Software Release

The first public release of the Türkiye Seismic Intelligence & Resilience Platform.

## Included

- Reproducible synthetic earthquake, exposure and satellite catalogues
- Live USGS earthquake-event retrieval for Türkiye
- AFAD export adapter without dependence on undocumented endpoints
- Data cleaning, quality reporting and provenance labels
- Daily event-rate anomaly screening
- Gutenberg–Richter b-value estimation
- DBSCAN spatial clustering
- Radius-based exposure screening for user-supplied points
- Public Sentinel-1 STAC discovery and same-orbit pair planning
- Processed InSAR displacement-point exploration
- CSV, Excel, Parquet and GeoJSON exports
- Streamlit dashboard and FastAPI service
- Bilingual English/Turkish GitHub Pages website
- Tests, CI, release validation, citation and Zenodo metadata

## Safety statement

This release does not predict earthquakes, issue early warnings, certify buildings or estimate
official damage and losses.

## Security statement

No credentials, private inventories or protected satellite assets are included.
