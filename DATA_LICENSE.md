# Data licensing and provenance

| Source | Role in this repository | Access | Important condition |
|---|---|---|---|
| USGS Earthquake Catalog API | Default live earthquake event feed | Public, no account required | Cite USGS and respect service limits |
| AFAD Earthquake Department | Türkiye official catalogue/reference source | Public pages; adapter is optional | Cite AFAD and follow provider rules |
| Copernicus Data Space STAC | Sentinel-1 acquisition discovery | Public catalogue search | Asset downloads may require a free account |
| User-supplied exposure data | Population, facilities or infrastructure points | Local upload | User is responsible for rights and privacy |
| Bundled demo data | Reproducible software demonstration | Included | Synthetic; not official and not operational |

No external provider dataset is relicensed by this repository. The MIT licence applies to source
code only.
